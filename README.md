## ⚡ Technical Overview

This portfolio is engineered as a **standalone, high-performance web interface**. By utilizing a single-file architecture, it ensures maximum portability and near-instant load times—essential for a clean professional presence.

* **Architecture:** Single-file `index.html` (HTML5, CSS3, Vanilla JS).
* **Design Philosophy:** Minimalist, security-focused aesthetic with responsive layouts.
* **Deployment:** Automated via GitHub Pages.
